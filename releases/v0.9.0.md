# v0.9.0 — protect, bring, reuse, and publish your writing

Released 2026-09-22. This source release adds automatic backups, reviewed migration, weighted inspiration decks and standalone Book HTML.

## What changes

- **Automatic backups:** open **Settings > Backups & recovery > Automatic backups** to enable a schedule, choose an interval, retention count and destination, and decide whether to include private sidebar conversations. Scheduling starts off and runs while the server is open, with one catch-up after downtime. History shows saved copies and failures; **Review & recover** verifies a copy before explicit restoration as new Stories. Retention removes only this workspace's owned scheduled copies after a successful new backup. On-demand copies remain separate.
- **Reviewed migration:** **Library > Migrate writing > Mixed files** reviews up to 20 supported files together. Bring bounded CHARX V3 and Backyard BYAF schema-1 character containers alongside existing character/world-info formats; review transcript speakers and alternate replies; convert supported foreign presets into inert writing recipes and optional inactive local profiles. Each file has its own review and result. Duplicate proposals default to skip, and saved receipts recover interrupted publication. Exact originals remain downloadable. Imported rules, connections and model work never activate themselves.
- **Inspiration decks and collections:** **Library > Inspiration** creates versioned decks with stable cards, tags, positive weights and explicit exclusions. Inspect exact odds and seeded previews, then deliberately record a draw. Old versions and results remain inspectable. Three editable starter collections are included. Share selected versions in a portable collection and review duplicate handling on import. In a Story, **Add to unsent input** appends a chosen card for your review; sending stays separate, and Story randomness remains under its existing controls.
- **Standalone Book HTML:** prepare a frozen Book and download **HTML** alongside DOCX and EPUB. Optional linked contents, semantic headings and embedded reading/print styles work offline without JavaScript. The file includes selected prose and publication metadata; author notes, model requests, private context and other tellings stay out. Literal markup is escaped. Existing Book selections and earlier prepared downloads retain their original text.

See the [README](../README.md), [migration matrix](../migration-compatibility.md), [inspiration contract](../inspiration-compatibility.md) and [HTML publishing guide](../html-publishing.md) for workflows and limits.

## Install or update

Download `prosperos-study-v0.9.0-source.zip` from the [GitHub release](https://github.com/vantaloomin/prosperos-study/releases/tag/v0.9.0), or check out the annotated `v0.9.0` tag. `source-manifest-v0.9.0.json` identifies the release commit and each bundled file; `SHA256SUMS.txt` verifies the ZIP and manifest. This is a source package. Dependencies and the built interface are installed locally; models and API credits are separate.

On Windows, extract the ZIP and run `install.bat`, then `launch.bat`. On macOS, run `bash install.sh`, then `bash launch.sh`. Runtime requirements and setup details are in the [README](../README.md#get-started-on-windows).

Before updating, save a workspace backup and stop the app. Keep your existing `data/` folder when replacing the application source, rerun the installer and launch again. Keep a backup from the previous version if you may need to downgrade. Automatic backups remain off until you explicitly enable them.

## Compatibility and recovery

Private archive format **54** adds accepted transcript and preset provenance, inspiration deck versions, recorded draws and collection originals. Older supported archives migrate through validated record groups. Restoration creates independent identities while preserving selected prose, historical pins, source files, frozen requests and recorded results. It does not replay model work or accept new story facts.

Local backup schedules and destinations never travel in archives. Migration staging queues, native import envelopes and prepared publication snapshots remain installation-local under their existing contracts; accepted foreign sources are archived with their published records. Restored Book selections can regenerate DOCX, EPUB and HTML. Portable inspiration collections contain selected deck definitions and inert metadata, without Stories, draw history, credentials or model connections.

Migration supports the explicit variants and size limits in the compatibility matrix. BYAF conversation history stays reference material in the character importer. Foreign macros and unsupported behavior remain literal or documented reference data. Importing does not establish equivalence with every feature of the source application. Current archives cannot be opened by older application versions.

Desktop, narrow, enlarged-text and reduced-motion layouts were inspected. These checks establish application behavior and recovery with controlled fixtures. Native macOS installation, packaged desktop delivery, broad live-provider writing quality, demanding-branch performance, dedicated e-readers and physical printers remain outside this verification.
