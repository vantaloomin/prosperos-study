# Prospero’s Study v0.7.5

Released 2026-09-19.

This update helps the writer bring earlier evidence into a new draft, shows which memory features are available, and makes continuity and wording corrections reviewable. Your accepted story remains under your control.

## What’s new

- **Memory readiness** shows the selected writer’s local recall, prewriting search, semantic setup, relationship links, and automatic preparation. Open the relevant settings directly from the status panel. Checking readiness makes no model requests.
- **Optional prewriting recall** can search earlier accepted prose before an ordinary Author-view draft. Semantic search and tentative relationship links help locate related originals. The draft receipt records supplied evidence, coverage, and fallback.
- **Revise continuity** creates an alternative from the draft’s saved evidence and your concern. Compare it with the original before choosing Keep.
- **Phrase check and optional cleanup** help review recurring wording. Cleanup preserves the original and never silently changes accepted prose.
- **Reading-time preparation** warms local indexes and supports optional interruptible background work on verified LM Studio native connections. Foreground writing takes priority.
- **Broader Library imports** add supported legacy character and lorebook formats, with previews and preserved source metadata.
- **Two illustrated guides** explain the agents and memory paths for [Narrative / Passive](../design/infographics/narrative-passive-agents-memory-v075.png) and [Roleplay / Active](../design/infographics/roleplay-active-agents-memory-v075.png).

The manuscript workspace, DOCX/EPUB publishing, model controls, and agent templates from v0.7.0 remain included.

## Start using the memory features

Open **Writing tools > Memory readiness > Open memory preferences** and choose **Long story**. Local recall needs no extra model call. Enable **Check earlier evidence before writing** if desired; semantic search and relationship-assisted prewriting require it. Add an embedding model for semantic search. Prepare older relationship links explicitly; automatic preparation is a separate opt-in for newly accepted prose.

Extra recall aids start off. Prewriting recall currently applies to ordinary Author-view drafts, not scene workflows or character-lens requests. Read the [setup guide and model-call costs](../README.md#keep-the-past-and-what-is-still-to-come) before enabling additional work.

## Updating and archives

Keep a private archive before updating if you may need to return to an older version. Install dependencies and rebuild the interface with the supplied installer after taking the release source.

**Archive format 37** preserves manuscripts, bookmarks, prompt guidance, cleanup variants, tentative links, and continuity-revision receipts together. Migration distinguishes the published v0.7.0 archive layout from development layouts that used overlapping version numbers. Restores preserve saved request bytes, create independent stories, disable automation, and do not resend model work. New format-37 archives require a version that understands that format.

## Verification and limits

The complete code-tree check passed **1,374 backend tests**, **94 frontend model tests**, Ruff, ESLint, TypeScript, and the production build. Desktop/mobile checks covered readiness settings, explicit revision, and an older restored manuscript. A controlled-provider exercise passed restore → write → revise → keep → fork → restart → export/restore. Two upstream test-client deprecation warnings remain.

The source code still matches the checksum manifest from that passing run; subsequent changes add documentation and infographic assets. See the [verification record](https://github.com/vantaloomin/prosperos-study/blob/v0.9.0/v075-release-readiness-goal.md).

Memory remains selective. Retrieved evidence and source-quoted links do not establish truth or guarantee that the writer uses the evidence correctly. Automatic continuity checking remains experimental. The current readiness pass did not remeasure live narrative quality or dedicated ebook-reader rendering.
