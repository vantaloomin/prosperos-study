# v0.8.0 — personal writing tools and an editable Companion

Released 2026-09-21. This source release adds personal writing tools, an editable Sidebar Companion and a direct path from setup to writing.

## What changes

- **Skip setup:** start writing directly from any unfinished wizard step, with entered choices and selected Library editions preserved. Empty titles become **Untitled Story**; no model is required and skipping starts no generation. Change settings later and recover an interrupted save without creating a duplicate Story.
- **Writing styles:** versioned Library profiles with optional prose, viewpoint, dialogue, rhythm and description preferences, unwanted habits, and author examples. Selected-sample analysis proposes editable guidance; publishing and Story adoption remain separate decisions. Requests retain their resolved style edition and samples.
- **Writing recipes:** editable starters, typed variables, task/model choices, reader lenses, optional style and chance settings, and portable files with explicit local reference mapping. Run recipe previews the complete sequence, then previews and starts each step explicitly. Saved runs retain reports, original inputs, attempts and final text proposals. Review-only recipes do not change text.
- **Tellings:** compare paths and changed passages, favorite or reversibly archive branches, and search across a Story with an explicit archived-path option. Shared passages are grouped without merging source permissions. Existing manuscript selections remain fixed to their selected prose.
- **Sidebar Companion:** the existing Collaborator can Pop Out into a separate window, follow or pin context, receive exact selected text or comparisons, and propose or explicitly apply scoped text changes. Rename, search, archive and reopen conversations. Saved drafts, requests, proposals and receipts synchronize across windows, with conflict review for competing edits.
- **Shared text changes:** add, insert, replace or update supported text destinations. Accepted passages create revised tellings with their later prose preserved. Versioned resources keep their publication/adoption rules. Apply records a durable receipt; Undo preserves independent newer work or offers an inverse proposal for review.

See the [README](../README.md#write-in-your-own-style) for the author workflow and the [implementation goal](../v080-implementation-goal.md) for measured development evidence.

## Install or update

Download `prosperos-study-v0.8.0-source.zip` from the [GitHub release](https://github.com/vantaloomin/prosperos-study/releases/tag/v0.8.0), or check out the annotated `v0.8.0` tag. The release also includes `source-manifest-v0.8.0.json` and `SHA256SUMS.txt` for verifying the source files and downloads. This is a source package; dependencies and the built interface are installed locally.

On Windows, extract the ZIP and run `install.bat`, then `launch.bat`. On macOS, run `bash install.sh`, then `bash launch.sh`. The [README setup instructions](../README.md#get-started-on-windows) include runtime requirements and platform details. Models and API credits are not bundled.

Before updating an existing workspace, save a workspace backup and stop the app. Keep your existing `data/` folder when replacing the application source, rerun the installer and launch again. Keep the older backup if you may need to downgrade. Open New Story and choose **Skip setup** to begin immediately, or continue through the guided setup.

## Compatibility and recovery

The current private archive format is **51**. It includes writing resources and import mappings, branch curation/comparisons, working documents and text-edit receipts, Companion drafts/pins/edit origins, sample-analysis history, and complete recipe runs/jobs/attempts/results. Older supported formats migrate through strict record-shape checks, including both historical layouts that used formats 32/33. A genuine archive from published v0.7.0 remains a committed regression fixture.

Restoration creates independent identities and preserves exact historical provider instructions/content. Frozen requests retain their original source IDs internally; separate bindings connect them to restored resources. Restoring, reopening, or restarting does not replay model calls, reapply text edits, advance recipe steps, or enable imported automation. Interrupted work requires explicit retry. Edited workspace prompts restored from another workspace cannot acquire authority over the host's defaults.

Companion conversations are included only when selected for a private archive. Excluding them retains the provenance needed for included text edits without copying private questions or discussion history. Portable style/recipe bundles use their own versioned format and exclude credentials, endpoint configurations, private conversations and unrelated Story material. Including author examples is explicit. Missing model or Library references need local mapping; unsupported settings remain visible and cannot silently execute.

Current archives cannot be opened by older application versions. Keep a backup made by the older version if downgrade may be needed. Book scene references are not automatically repointed when prose is revised or a branch is archived. Existing DOCX/EPUB workflows remain part of the final compatibility gate.

## Verification status

The four original author-facing workstreams and their required implementation gates are complete. Before the Skip setup addition, the full pipeline passed **1,756 backend tests**, **110 UI-model tests**, Ruff, ESLint, TypeScript and the production build. All 1,082 source/test/build files remained unchanged throughout that verification. The combined acceptance scenario and nine release browser checks passed, including genuine earlier-release manuscript preservation. [The validation audit](../v080-validation.md) maps requirements to evidence, records the corrected restore regression and distinguishes automated, rendered-browser and real restart checks.

The later [Skip setup addition](../v080-skip-setup-goal.md) passed **113 UI-model tests**, **7 existing onboarding backend tests**, **24 Chromium browser checks**, ESLint, TypeScript and a fresh production build. Desktop and narrow screenshots were inspected; the browser scenario recorded no model calls and no unexpected errors. Checks include retained choices, manual writing, duplicate activation and recovery of the same saved request after reload. The complete backend suite was not rerun for this bounded frontend change, and native mobile keyboards and other browser engines remain untested for the shortcut.

[Representative live evaluation](../v080-output-evaluation.md) made 15 calls to one loaded local model. Two contrasting style revisions, a complete recipe, scoped Companion shortening and sample-analysis suggestions completed after documented parser compatibility work and explicit retries. The model introduced details/actions that require author review and missed a style instruction. These observations are separate from deterministic lifecycle success.

Controlled-provider checks establish scope, persistence, recovery, and application behavior. They do not establish writing quality, universal style adherence, reliable novel-length continuity, or behavior on every provider. The Pop Out uses ordinary browser windows; popup permission and geometry depend on the browser and operating system. Native macOS, physical multi-monitor movement and dedicated ebook-reader behavior remain unverified. The live-output evaluation covers one local model only.

Automatic backups, cross-branch passage splicing, packaged installers, research/MCP collections, voice, image generation, and simulated-character Companion / Date Mode are outside this release.
